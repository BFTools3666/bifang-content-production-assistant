# 匿名统计与版本检查说明

毕方内容生产助手的匿名使用统计默认关闭。只有用户在“设置”中明确开启后，应用才会在主窗口启动或首次启用时尝试发送当天唯一一条 `daily_active` 事件；关闭后不再发送后续事件。

统计事件只包含：协议版本、随机事件 UUID、固定事件名、应用 ID、应用版本、本应用独享的随机安装 UUID、平台、处理器架构、公共服务 SDK 版本和 UTC 发生时间。它不包含账号、硬件序列号、IP 字段、AI 服务配置、凭据、文章标题、正文、图片或其它创作内容。安装 UUID 和统计同意状态只保存在本应用的数据目录；北京时间日期在联网前认领，即使请求失败，当天也不会自动重试。

应用会在主窗口启动后检查一次版本，也允许用户在“关于”页手动检查。版本请求发送到固定 Kaiwhale 网关，只包含当前发布流 code、当前版本路径，以及按负责人明确要求固定在 Rust 可信层的 App Key 和 App Secret。服务返回的提示内容始终按不可信纯文本展示，下载地址经过 Rust 可信层校验后才交给系统浏览器。强制更新只允许打开下载页或完整退出应用；暂停更新分发不会停止应用。

这些公共服务不会上传本地工作区或 AI 内容，也不会自动下载、安装更新或购买 CloudBase 资源。当前云端资源位于 CloudBase 环境 `bftoos-sh-d3ga7hahz59229f0a`；需要删除已发送的匿名统计记录时，请通过项目负责人 `arden` 发起处理。
