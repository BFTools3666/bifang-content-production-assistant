# 文章生产工作台增量规格

- 状态：Approved（用户 2026-10-09 明确要求修复标题生成、更新入口并优化运营人员文案与设置入口）。
- 产品：毕方内容生产助手；既有原生身份、长文章平台和用户数据契约继续有效。
- change_id：`FEAT-BATCH-AI-TITLES-20261009`
- required_version：`0.2.25`（本周期功能锁已开启）；当前目标版本由根 Cargo 管理。

## 用户与目标

服务需要持续生产长文章的运营人员。使用者不必先写完整标题，也不必理解工程术语。文章面向的行业、受众和用途由使用者决定，不把产品定位限制为技术文章。

## 本次包含

1. 首页展示批量文章生产工作台；从主题、参考作品或已存风格生成单篇文章的流程保持可达。
2. 主题、平台和可选标题要求生成 5、10 或 20 个候选；复用已保存的正文文本 AI。没有 Key 时引导接入，不发起生成。
3. 勾选候选后显式加入工作台，才通过原用例保存文章任务。生成候选本身不保存文章、不生成正文；无效或重复候选失败关闭。
4. 失败保留当前输入，不自动重复可能计费的 AI 请求。新任务加入后清除旧筛选，并按创建时间展示，避免新标题被隐藏。
5. 设置的 AI、飞书、生成要求、生成记录使用两列入口与明确说明；操作提示与实际路径一致。
6. 更新检查显示处理进度，区分后台未登记、网络失败和协议错误；保留公司的公共统计与安全下载规则。
7. 更新日志读取与发布规范一致：最近十版，双语、每类十条；发行版构建前验证实际日志与版本、资源映射。

## 本次成功标准与边界

标题、正文、审核、配置、版本接口和打包的相关回归通过；Windows 安装包在实际设备验证新增标题加入任务、正文生成、保存重启、设置导航和更新日志读取。真实更新查询与下载还依赖管理员提供有效的版本后台登记，不能把错误提示验证当成更新成功。产品名称和安装身份不变；未新增发布平台，不接入应用内购买或自动安装更新。
