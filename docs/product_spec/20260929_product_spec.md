## 新增目标

1. GUI 可选择向指定 CloudBase 环境发送隐私最小化的匿名每日活跃事件，用于统计应用实际使用情况。
2. GUI 通过共享 `application-version` API v1 发现 Windows x64 与 macOS arm64 稳定发布流的更新策略，并在关于页展示可选更新或以根级门执行强制更新。

## 产品与安全边界

- 统计默认关闭，必须由用户在设置页明确开启，且可以随时撤回；联网前按北京时间持久认领日期，每个安装每天最多尝试一次，失败不自动重试。
- 统计只允许冻结的十字段 `daily_active` 载荷；随机安装 UUID 不来自账号、硬件或现有业务数据，不上传 AI 配置、凭据或任何创作内容。
- 版本服务使用固定 CloudBase origin、固定发布流 code 和严格七字段响应。`x-app-key` 与 `x-app-secret` 只由构建宿主注入 Rust 可信层，缺失或非法时零 GET 并显示未配置。
- 下载 URL 只由 Rust 保存与二次校验，WebView 不得传入任意 URL。提示正文按纯文本展示；强制更新根级阻断普通功能，只保留打开下载页和完整退出。
- 官方 Tauri updater 继续保持 `NotConfigured`、无 endpoint、零出站；本功能只做版本发现，不自动下载或安装更新。
- 本范围不包含广告、账号体系、跨应用身份、生产密钥生成、CloudBase 付费升级、版本记录发布或渠道发布。
