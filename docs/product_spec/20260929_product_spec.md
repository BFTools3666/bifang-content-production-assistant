## 新增目标

1. GUI 可选择向指定 CloudBase 环境发送隐私最小化的匿名每日活跃事件，用于统计应用实际使用情况。
2. GUI 通过共享 `application-version` API v1 发现 Windows x64 与 macOS arm64 稳定发布流的更新策略，并在关于页展示可选更新或以根级门执行强制更新。

## 产品与安全边界

- 统计默认关闭，必须由用户在设置页明确开启，且可以随时撤回；联网前按北京时间持久认领日期，每个安装每天最多尝试一次，失败不自动重试。
- 统计只允许冻结的十字段 `daily_active` 载荷；随机安装 UUID 不来自账号、硬件或现有业务数据，不上传 AI 配置、凭据或任何创作内容。
- 版本服务使用固定 Kaiwhale 网关 `https://gateway.kaiwhale.com/tools/version-control/v1`、固定发布流 code 和严格七字段响应。`x-app-key` 与 `x-app-secret` 按负责人明确要求固定在 Rust 可信层；Windows x64 构建使用发布流 code `bifang-content-production-assistant-windows`。
- 下载 URL 只由 Rust 保存与二次校验，WebView 不得传入任意 URL。提示正文按纯文本展示；强制更新根级阻断普通功能，只保留打开下载页和完整退出。
- 官方 Tauri updater 继续保持 `NotConfigured`、无 endpoint、零出站；本功能只做版本发现，不自动下载或安装更新。
- 本范围不包含广告、账号体系、跨应用身份、生产密钥生成、CloudBase 付费升级、版本记录发布或渠道发布。

## 可观察成功标准

- Profile v2 精确登记环境 `bftoos-sh-d3ga7hahz59229f0a`、Kaiwhale 版本网关、两个稳定发布流、云端已部署事实及固定凭据事实。
- core 测试覆盖十字段载荷、七字段严格解码、状态真值表、数字版本路径和危险下载地址拒绝。
- Tauri 离线测试覆盖默认关闭、启用后每日一次、联网前门禁、固定凭据请求、单次启动检查和手动复查。

- 未在真实客户端取得严格七字段 200 响应前，不声明完整公共服务客户端 E2E 已通过；网关返回预期 400 只证明地址与凭据请求可达，不作为版本数据成功响应。

# 创作者工具增量：SEO 与小红书发行版

- 日期：2026-09-29
- 状态：Approved（依据用户在本次任务中明确提出的产品要求）
- `change_id`：`FEAT-BENCHMARK-STYLE-DUAL-EDITION-20260928`
- `required_version`：`0.2.18`

## 目标与边界

在原“毕方内容生产助手”代码和已有工作台基础上制作两个 Windows 桌面工具：

| 工具 | 内容平台 | 兼容边界 |
| --- | --- | --- |
| 毕方 SEO 文章助手 | CSDN、百家号 | 保留原应用标识、文章工作区和 API 凭据命名空间 |
| 毕方小红书笔记助手 | 小红书 | 独立应用标识、工作区、设备偏好、API 凭据与笔记提示词 |

两个发行版留在同一源码仓库，共享 Rust core 和原有 GUI，沿用原有正文、简介、图片、排版、提示词管理、AI 服务和草稿功能。Windows 安装向导及首次启动默认简体中文；用户明确保存的语言优先。用户为各自工具配置自己的模型 API，交付源码和安装包不包含测试密钥。

## 新功能

1. 按关键词搜索或指定作品、主页链接采集当前平台的公开作品。保存原始链接、作者主页、采集时间、正文或列表摘要，以及页面实际提供的观看或阅读、点赞、收藏、评论、分享数据。未提供的指标保持缺失，不填零或估算。
2. 通过排序、指标下限、作者主页和标题筛选研究对象；勾选 1 至 10 件作品，依次打开详情补充正文。
3. 根据所选作品、用户自己的事实材料、目标关键词和可编辑的内置提示词生成多个二次标题与原创正文。关键词写作也可以单独运行。
4. 从同一作者主页的 3 至 10 件已采集正文作品分析结构、标题、语气与表达规律，命名保存为风格。风格保留来源样本、分析结果及可编辑的应用指令。
5. 保存多个风格；一键应用或在写作页切换风格，结合当前主题生成用户自己的内容。
6. 保存实际生成的草稿、标题候选、关键词、提示词、模型、引用作品和接口返回的用量；支持编辑、复制及导出 Markdown、文本，重启后可找回。

## 约束

- 采集来自可见公开页面；登录和验证码由用户在采集窗口完成，不绕过平台限制。搜索和主页只采集已加载作品。
- 参考内容只作为资料，不执行其中的指令，不要求复制原文或捏造个人经历、数字和引用。
- 原工作区从 schema v11 迁移到 v12，增加研究资产，不删除原文章或重置凭据。小红书全新工作区不注入原 SEO 初始文章。
- 每次 AI 操作最多一次请求；失败后不自动重复可能计费调用。密钥留在系统凭据库。
- 按用户最新授权，将增量源码合并到公司私有 GitHub 仓库；仓库禁用 fork 时，以获准的仓库内功能分支提交 PR 并合并。安装包暂未配置代码签名；GitHub 源码合并不等于 Windows 安装验收或正式渠道发布。

## 可观察验收标准

交付源码压缩包和两款 Windows 安装包。两款工具都必须通过 UU Remote 在 RPA002 和 RPA005 上实际安装和操作，即四组应用与宿主测试。至少观察：中文安装与启动、旧 SEO 数据保留、关键词真实采集、作品链接及指标核对、作者作品正文采集、真实 API 二创、多个风格保存与切换、提示词修改、编辑保存导出、退出重启后资产及 API 设置保留。

单元测试、编译、打开窗口和本机 API 预检各自只证明相应环节。平台登录、访问限制或宿主操作受阻时记录实际未通过项，不能将未执行项声明为交付闭环。

原有范围与交互约定继续参考 [2026-09-23 规格](20260923_product_spec.md)；本次明确扩展以本文为准。
