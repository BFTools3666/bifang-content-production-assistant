## 产品目标

本产品是一款面向批量内容运营的本地桌面工作台。用户在类似飞书多维表格的 Grid
中管理多篇文章主题，选择需要处理的行后启动固定 SOP，并在同一行观察正文、简介、
配图和格式产物的生成状态，精确重试失败阶段，最后审核和批准文章包。

首要消费者是一次生产几十篇文章的内容运营人员。GUI Grid 是主要工作界面，共享
Rust core 是任务规则与状态的唯一事实源；CLI 提供只读 SOP 描述，以及对显式本地
工作区的文章列表与单篇详情查询。

## 产品身份

- 中文展示名称固定为“毕方内容生产助手”，英文展示名称固定为 `Bifang Content Production Assistant`。
- 项目 ID 固定为 `bifang_content_production_assistant`，kebab 前缀固定为 `bifang-content-production-assistant`；仓库根目录以及 CLI、core、GUI 目录、crate、package 和二进制名称均由该项目 ID 派生。
- Tauri identifier 固定为 `com.arden.bifang-content-production-assistant`，受限深链接固定为 `app-bifang-content-production-assistant://restore`；系统凭据服务、设备级偏好键、E2E 环境变量和测试临时路径使用相同的新产品前缀。
- 当前维护树不保留被撤销的错误产品身份、兼容别名或旧身份回退。旧应用命名空间中的本地数据、设备偏好和系统凭据不会自动读取、复制或删除；如需迁移，必须另行确认数据与凭据边界。

## 核心输入与输出

每一行至少包含文章标题，可选包含关键词和内容要求。运行时冻结该行输入、各步骤
Prompt 模板版本以及所选 AI Provider/模型配置。

每一行最终形成一份可追溯文章包：标题和输入约束、Markdown 正文、文章简介、一张
配图及生成元数据、从正文确定性派生的 HTML，以及不可变创建时间、阶段状态、实际耗时、
Provider 原样 token 用量、错误、尝试和审核结论。

## MVP 包含范围

### 文章只读 CLI

- `article list --app-data-dir <DIR>` 按 GUI 相同的默认顺序返回全部文章：创建时间倒序，
  相同创建时间按稳定文章 ID 倒序。列表包含身份、输入、包/行版本、总体/审核/阶段状态和
  创建/更新时间，不提供分页、筛选、排序覆盖或写入参数。
- `article get --app-data-dir <DIR> --id <ID>` 使用大小写敏感的稳定 ID 精确查询，返回上述
  摘要、当前 Markdown/简介/HTML、配图与 AI 原图存在性、人工配图编辑修订，以及尝试、
  批准包和包快照数量；不返回当前或任何历史中的本地图片引用与历史正文。
- 两个命令均支持既有人类输出和全局 `--json` 四字段信封，机器命令名分别固定为
  `article.list`、`article.get`。参数错误退出 `2`，资源不存在退出 `3`，工作区不可用退出
  `6`，无效快照或模式不匹配退出 `10`；JSON 失败保持 stdout 单文档、stderr 为空。
- `--app-data-dir` 必须由用户明确传入现有绝对非符号链接目录；CLI 只接受其中现有的
  `content-workbench.sqlite3` 普通文件，不扫描用户目录、不推断平台路径、不创建目录或数据库。
- CLI 只以 SQLite read-only、禁止创建模式读取当前 schema v11 快照；不执行迁移、规范化、
  初始数据注入、中断恢复或任何保存。旧/未来 schema 提示先启动当前桌面应用，不做半解析。
- 查询不读取图片文件、Provider、系统凭据、网络、stdin 或外部进程，不触发 AI 或飞书调用。

### Grid 与真实初始数据

- 批量粘贴多行标题，空行不创建记录，重复标题保留为独立记录。
- 支持选择、全选当前结果、搜索、状态筛选、排序、预检和“运行所选”。Grid 展示不可变创建
  时间与更新时间；全新进程默认按创建时间倒序，相同创建时间按稳定文章 ID 倒序，用户可在
  本进程切换按更新时间、标题或状态排序。
- Grid 固定为“选择、文章信息、正文、简介、配图、格式”六列；文章信息格聚合标题、文章包版本、
  总体状态、创建/更新时间、错误摘要和查看详情动作。表格在 960px 最小窗口内自适应分配列宽，
  阶段按钮、文本缩略图和配图缩略图允许收缩与换行，Grid 与页面均不得出现横向滚动条。
- 正文、简介、配图和格式状态格各自提供明确的“生成/重新生成”按钮。按钮只运行所点阶段，
  成功后不自动排队任何后续阶段；依赖或当前步骤 AI 未就绪时在原位置说明最早缺失项。
- 四个阶段格只在真实排队或生成状态显示转圈；运行尝试按开始时间逐秒显示已用时间，终态固定
  显示最近尝试的实际耗时。AI 尝试显示 Provider 实际返回的总 token，缺失时显示“Token 未提供”
  且不估算；本地格式固定为“0 Token · 本地处理”。预览读取、详情打开与后台查询不启动生成动效或计时。
- 未开始阶段在当前文章包内首次生成；已经完成、失败、过期、取消或中断的阶段使用重新生成
  语义并创建受保护的新文章包版本。单步命令绑定用户看到的行版本与文章包版本，陈旧界面和
  快速重复点击不得形成第二次排队或外部请求。
- 单步配图在出站前展示当前图片 AI 的名称、修订、模型、尺寸和水印并确认可能计费；打开或
  取消弹窗保持零出站，一次确认最多发出一次请求，失败后必须关闭并重新确认。
- 正文和简介阶段有产物时，在对应 Grid 单元格显示最多三行的文本缩略内容；点击缩略内容
  打开该文章详情的对应正文或简介页签，可继续手动编辑和保存。查看产物与单步生成是两个
  独立动作，点击缩略内容不得触发 AI 请求。
- 配图阶段有受管本地产物时，在对应 Grid 单元格显示固定尺寸缩略图；点击缩略图打开文章
  详情的配图页签查看完整图片。缩略图只在进入可视区域附近时由原生层按固定上限解码和缩放，
  不向 WebView 暴露本地路径或远端临时 URL；离开可视区域后释放行内缩略图。
- 已完成后因上游编辑而过期的旧产物可以继续缩略显示，但同一单元格必须同时保留当前阶段
  状态，不能把旧预览误表示为当前成功产物。复选框、预览、状态、单步生成和查看详情分别
  由独立语义动作拥有。
- 应用内置用户飞书表 `QYSEO文章v1.3.0` 当前 14 条真实文章标题，作为一次性初始草稿；
  对应飞书标签 `跨境电商/营销策略` 原样作为行级关键词，文章类型 `原创` 原样作为内容要求。
- 初始数据只在内容仍为空白的普通工作区写入一次；已有 Provider/Prompt 原样保留，已有
  文章、运行历史或执行绑定的工作区不注入。用户删除种子后不得在重启时自动恢复。
- 初始数据不会自动选中、自动运行或发起网络请求。

### 固定内容 SOP

1. 校验标题和行级输入。
2. 通过正文 AI 生成 Markdown 正文。
3. 通过简介 AI 基于指定正文版本生成文章简介。
4. 通过图片 AI 基于标题、正文和简介生成配图。
5. 从规范正文确定性生成 Markdown/HTML 格式产物，并在展示与复制边界把当前受管配图动态组装为自包含格式投影。
6. 校验必需产物并进入待审核。

正文、简介、配图和格式分别具有独立状态。普通重试沿用当前文章包版本，只执行失败
或中断阶段；重新生成创建新版本，不能覆盖旧成功产物或已批准版本。
单步运行只冻结目标阶段需要的 Prompt、AI 服务和凭据；本地格式步骤不读取任何 AI 凭据。
单步运行记录必须标识目标阶段，并按该阶段成功、失败、中断或取消收口，不能把“正文已成功、
整行仍为草稿”误报成批次失败。

### 详情与审核

- 详情 Drawer 展示和编辑输入、正文、简介、配图、格式、血缘与历史；阶段历史逐字段展示输入、
  输出、总 token 与实际耗时。Provider 未返回的字段保持“未提供”，不得由其它字段反推。
- 正文、简介、配图和格式页签的阶段按钮只运行当前阶段，成功后不自动排队任何后续阶段；按钮附近持续显示单步边界，依赖、当前步骤 AI 或运行锁未就绪时说明最早缺失项。它们与 Grid 复用同一行版本、文章包版本、单步运行记录和目标阶段 worker；配图复用同一 Provider 修订与可能计费确认。
- 配图页签提供独立基础编辑器：查看支持 `25%–400%` 缩放、适应窗口、`100%`、拖动画布、
  全屏与重置查看；编辑支持自由裁剪、`1:1`/`4:3`/`16:9`、左右 `90°` 旋转、水平/垂直
  翻转、撤销/重做和恢复 AI 原图。查看操作和关闭全屏保持零持久化、零写 IPC；只有用户明确
  保存才创建新配图文件和新文章包版本，未保存关闭详情必须确认。
- 格式页把 Markdown 与 HTML 作为等宽并列选项卡，不再上下堆叠；每种格式都提供源码和
  解释后的渲染效果，默认进入 Markdown 渲染效果。渲染正文只接受严格白名单结构并置于无
  脚本、无出站的 sandbox 文档中，原始 HTML 的脚本、事件属性、表单、外部图片和导航目标
  不得进入可交互预览。
- 当前受管配图只通过文章 ID 的既有安全读取命令进入 WebView。Markdown 与 HTML 在内存中
  分别组装含完整图片 Data URL 的自包含复制投影，不能写入 SQLite、规范正文、本机路径、
  `file://` 或方舟临时 URL；源码显示折叠超长图片负载，复制保留完整数据。有图但读取失败时
  禁止复制缺图降级内容，重新读取保持零 AI 调用。
- 过期配图或目标文章处于排队/运行中时仍可查看 AI 原图和已有编辑参数，但保存按钮禁用并显示
  稳定原因。保存失败、乐观锁冲突或像素处理失败时保留前端草稿，AI 原图、当前产物、包历史和
  已批准历史均不得被覆盖或删除。
- 正文修改后使简介、配图和格式过期；简介修改后使配图过期，完成重新生成前禁止批准。
- 批准绑定不可变文章包版本，后续重新生成不改变历史批准版本。

### Prompt 与阶段式 AI 配置

- 正文、简介、配图分别管理稳定 ID、版本、变量声明和 Prompt 内容；本地预览不调用外部 AI。
- AI 配置以 SOP 步骤为首要信息架构，必须明确分成“正文 AI”“简介 AI”“图片 AI”三个
  可切换区域。每个区域只展示和编辑该步骤的默认服务、模型与适用参数，不能把三阶段表单
  并排堆叠为一个难以辨认的服务表单。
- 同一底层 AI 服务可被一个或多个步骤复用；服务名称、API 根地址、启停状态和系统凭据只
  维护一份。编辑某一步骤时必须完整保留该服务另外两个步骤的模型、参数和默认位。
- 服务连接管理与步骤模型配置分区展示。服务连接管理负责名称、API 根地址、密钥状态、启停、
  密钥轮换与安全删除；步骤区域负责该步骤模型、参数、默认服务和适用的连接测试。
- 新服务从当前步骤进入配置，只要求当前步骤的模型；未显示的另外两个步骤不会被隐式设为默认，
  后续可在各自步骤中单独补充。
- 正文和简介连接测试发送最小文本请求。图片步骤提供独立的“生成测试图片”操作：每次先明确
  提示可能产生一次图片费用并取得确认，再使用已保存的服务修订、模型、尺寸、水印和固定的
  无文章数据 Prompt 真实生成一张图片。原生层完成与正式配图相同的下载、大小和格式校验后，
  只向当前弹窗返回受限的内存预览；关闭弹窗即清除，不写入文章、素材目录、执行绑定或运行记录。
- 初始正文和配图模板继承飞书表当前真实生成约束，并继续带入行级关键词、内容要求与简介。
  飞书未暴露独立简介公式，简介模板保留当前产品的 80–120 字直接输出契约。
- 格式阶段继续使用本地确定性 Markdown→HTML 转换，不消耗 AI 调用。
- MVP 提供 OpenAI-compatible 文本与图片调用，并为图片阶段提供独立的火山方舟 Ark v3
  图片服务类型。OpenAI 服务可以同时作为正文、简介、配图默认服务；火山方舟图片服务只
  能作为配图服务，不得出现在正文或简介的可选服务中。
- 火山方舟图片服务保存 API 根地址 `https://ark.cn-beijing.volces.com/api/v3`，运行时固定
  调用 `images/generations`；模型字段使用推理接入点 ID。首版固定单图、非流式、URL 返回
  协议，即 `sequential_image_generation=disabled`、`response_format=url`、`stream=false`，
  允许用户配置 `2K` 尺寸、水印开关和超时。固定协议字段在界面中说明而不要求重复填写。
- 火山方舟返回的临时签名 URL 必须由原生适配器立即以不携带 API 密钥的独立请求下载，经过
  来源、重定向、大小和图片格式检查后写入受管本地文件；URL 本身不得进入 SQLite、WebView、
  日志或错误消息。生成 POST 已成功后若下载失败，该阶段必须明确标记为不可普通重试，避免
  “仅重试失败”再次生成并重复计费；Ark POST 发出后超时、响应中断，或应用在运行中配图阶段
  退出，也必须以同样的“结果未知”门禁恢复。用户仍可在核对方舟记录和网络后明确执行重新生成。
  现有 OpenAI Base64 图片路径和历史执行绑定继续保持原冻结语义。
- 方舟 TOS 下载必须兼容 Clash/Mihomo TUN 对严格官方主机返回的纯 `198.18.0.0/15` Fake-IP，
  但不得把该网段视为一般公网地址。只有完整 DNS 答案都属于公网或都属于该合成网段时允许连接；
  混合答案、其它私网/保留地址和非官方主机继续拒绝，并保持 TLS 主机校验与禁止重定向。
- 桌面二进制提供显式方舟单次诊断模式：预检只读工作区并验证默认方舟配置和系统凭据，零生成
  请求；真实执行必须带用户本次付费确认和独立输出目录，复用正式 transport、固定测试 Prompt、
  一次最多一个 POST 且不自动重试。输出不得包含 API Key、凭据引用、完整临时 URL、签名参数、
  Prompt 或响应正文，只保留阶段、请求次数、MIME、字节数、像素尺寸和本地测试图路径。
- 图片测试确认一次至多发出一个生成请求，不自动重试。测试请求超时、响应中断、成功响应无法
  解码或方舟图片下载失败时，必须提示结果可能已经计费并要求用户先核对服务商控制台；再次测试
  需要关闭结果并重新取得一次明确确认。
- AI 服务可以启用或停用。停用时自动解除其阶段默认位，禁止新的连接测试、批次、重试或
  重新生成选择该服务；已经冻结并开始的批次仍按原绑定收口，如需立即停止由用户取消批次。
- AI 服务只有在不承担任何当前步骤分配时才能删除；历史文章包执行绑定不再阻止用户从连接
  列表删除它。删除会保留历史绑定中的冻结非秘密配置和文章血缘，只解除目标 Provider 的
  历史凭据引用，并把当前及历史中已不再被其它服务使用的凭据加入可重试安全清理队列。
  受影响旧阶段不能使用已删除连接普通重试，必须选择当前 AI 后重新生成并建立新绑定。
- 用量只解析真实响应字段：Chat Completions 的 `prompt_tokens`、`completion_tokens`、
  `total_tokens`；OpenAI-compatible 图片的 `input_tokens`、`output_tokens`、`total_tokens`；
  火山方舟图片实际返回的 `output_tokens`、`total_tokens`。图片计数、像素、Prompt 长度和模型
  上限均不得换算成 token；响应缺少 usage 或单个字段时保持缺失并继续兼容。Provider 已返回
  usage 后即使产物校验、本地保存或方舟临时图片下载失败，原值仍随对应失败尝试保存。
- 自定义地址只能由用户明确录入，必须为受信任 HTTPS 服务。测试或运行会发送密钥和内容；
  保存、启停、删除和 Prompt 预览本身不联网。
- API 密钥只写入系统凭据库，不写入 SQLite、日志、截图、错误或聊天消息。

### 云文档连接器与显式文件同步

- 连接器是四阶段 SOP 之外的交付模块，不增加第五个生成阶段，也不因文章生成或批准而自动出站。
  提供独立“连接器”一级页面和飞书 CLI 发布目标，后续连接器可沿用同一配置与同步边界扩展。
- 飞书发布依赖用户独立安装并配置的官方 `lark-cli >= 1.0.96, < 2.0.0`。2.x 尚未完成兼容验证。
  每个发布目标只保存 CLI profile
  名称、目标文件夹 Token、默认格式、启停与默认项等非秘密信息；身份固定为 `user`，应用不读取、
  保存、复制、切换或删除 CLI token，也不调用 shell 或允许用户填写任意可执行命令。
- 配置保存、启停与删除本身不联网。用户显式执行“测试连接”时，应用同时检测 CLI，并以固定参数
  调用 `lark-cli`：先检查版本和所选 profile 的用户身份，再只读列取目标文件夹。测试不得创建或修改
  远端文件；未安装、版本过低、profile 未配置、未登录、缺少权限或文件夹不可访问均返回稳定安全
  状态，不展示 token、原始响应正文或本机配置路径。应用不自动安装 CLI，也不发起或接管登录。
- 文章格式页只列出已经启用且显式 profile 完整的发布目标。用户在 Markdown/HTML 当前格式内
  选择目标并再次确认后，CLI 版本、用户身份和文件夹访问会在写入前重新校验，随后才把包含当前
  受管配图 Data URL 的自包含产物发布到目标文件夹：
  Markdown 使用 CLI 原生 Markdown 文件创建，HTML 作为原始 `.html` 文件上传；文件名包含冻结
  文章包版本。首版不把 HTML 静默转换为原生飞书 Docx，也不新增第三种格式。
- 同步绑定用户看到的行版本、文章包版本、连接器修订和格式，只有当前格式阶段成功且内容完整时
  才能出站。单次确认最多一个上传请求，不自动重试；相同任务、文章包、连接器修订和格式已有
  成功记录时直接复用，不产生重复文件。不同文章包或连接器修订生成新的带版本文件。
- CLI 子进程使用固定可执行名与参数数组、显式 `user` 身份、所选 profile、有界超时和输出上限；
  Markdown 内容通过 stdin 传入，HTML 只在受控临时目录创建相对路径文件。退出码、JSON `ok`、
  身份、权限、限流、超时、过大输出和无效响应均映射为不含秘密的稳定错误；失败后由用户重新
  确认，不能后台重发。上传产物不得超过 20 MB。
- 删除发布目标只移除当前非秘密配置，不修改共享 CLI profile。历史同步记录保留连接器名称、修订、
  文章包、格式、文件名、远端 file token 与完成时间，不保留 token、原始 CLI 输出或文章全文。

### 本地持久化与恢复

- 文章、文章包、阶段状态、模板、非秘密 Provider 配置和一次性初始数据版本在重启后保留。
- 当前配图同时保存不可变 `original_image_ref`、既有 AI `image_lineage` 和独立人工编辑血缘。
  人工血缘只记录来源图片 attempt、编辑 UUID、保存时间与规范化整数编辑参数，不创建虚假
  `StageAttempt`。每次保存从 AI 原图按“裁剪→旋转→翻转”重算，写入受管目录的新 UUID 文件，
  再以行版本、包版本、图片 attempt 和编辑修订乐观提交；失败只清理本次新文件。
- 工作区 schema v8 为旧工作区当前包、包历史和批准历史中的每份 `image_ref` 分别补为自己的
  原图引用；新 AI 图片成功后把该图片设为新原图并清空旧人工编辑血缘。WebView 的聚合视图会
  同时清空当前与全部历史中的 `image_ref`、`original_image_ref`。
- 工作区 schema v9 为旧文章补齐不可变 `created_at_ms`：优先选择阶段尝试开始、包历史捕获、
  批准历史和已有人工编辑时间中的最早正数证据，完全没有其它证据时才回退 `updated_at_ms`。
  新文章创建时一次写入；编辑、重新生成、图片保存、审核和恢复只更新 `updated_at_ms`。
  阶段尝试新增可空逐字段 token 用量；旧尝试迁移后保持“未提供”，不生成估算值。
- 工作区 schema v10 为旧工作区初始化空连接器配置、独立凭据引用/待清理集合和文档同步记录；
  迁移不读取或复制任何系统凭据，重复打开保持幂等。非秘密连接器配置和成功同步记录随工作区保留。
- 工作区 schema v11 把飞书连接器切换为 CLI 发布目标：保留连接器 ID、名称、文件夹、格式、历史
  和同步记录；原当前修订进入历史，并建立新的停用修订且清除默认位，必须由用户选择 profile 后
  重新启用。旧 App Secret 引用只进入既有可重试安全清理队列，不迁移为 CLI 凭据；二次打开幂等。
- v6 当前 Provider 若精确使用方舟完整图片端点、未承担文本阶段且已有图片模型，升级时转换为
  专属方舟类型和 `2K` 水印协议；保留原服务 ID、修订、超时、默认位与系统凭据引用，不读取或
  复制密钥，不改写 Provider 历史或已冻结文章执行绑定。
- AI 页面当前步骤属于进程内页面状态，跨路由返回时保留；应用真正退出后恢复为正文 AI。
  工作台排序、格式页当前 Markdown/HTML 选项卡及源码/渲染模式同样只在进程内保留；真正
  退出后分别恢复创建时间倒序、Markdown 与渲染效果。
- 产物与成功状态原子保存；异常退出后的运行中阶段恢复为可重试的中断状态。
- 批次具有有界并发、超时、取消归属和按 Provider 限流；未配置或已停用时零出站。

## 状态与业务不变量

- 总体状态由阶段状态和审核状态推导，GUI 不直接写入。
- 待审核要求全部必需阶段成功且无过期产物。
- 每个派生产物记录输入版本、模板版本、Provider、模型和尝试 ID。
- 创建时间一经写入不可变；任何生成、编辑、图片保存、审核、恢复或查询都不得改写。
- token 用量逐字段保存 Provider 原值；缺失字段保持缺失，总量不得由输入/输出相加补齐。
- 人工配图产物保留原 AI 生成血缘，并另外记录可审计编辑血缘；任何保存都建立派生文章包并先
  快照当前包，已批准历史保持不可变。
- 同一任务版本与阶段的普通重复执行具备幂等语义。
- 人工编辑、审核结论和已批准版本不得被批量操作静默覆盖。
- 外部 AI 调用只能由用户明确测试、运行、重试或重新生成触发；“运行所选”的确认预览只校验
  非秘密配置与凭据引用，不读取系统凭据库，用户确认正式启动后才读取所需密钥。
- 飞书写入只能由格式页的单篇、单格式明确确认触发；连接测试、页面打开、后台刷新、文章生成、
  批准和重启恢复均不得创建文件。同一成功同步键必须幂等复用。
- CLI 文章查询不得改变 SQLite 字节、文件集合、文章时间戳、阶段状态、运行记录或任何其它业务状态。

- AI 服务页首屏清楚出现且只出现“正文 AI”“简介 AI”“图片 AI”三个步骤入口；切换后编辑区

- 修改并保存正文 AI 后，提交到 core 的简介模型、图片模型、两者参数及默认位与保存前完全一致；
  简介 AI 和图片 AI 的对称场景同样成立。
- 新增服务时只有当前步骤默认位可被设置，另外两个未显示步骤不会被隐式设为默认。
- 关闭页面再返回时仍选中上次使用的 AI 步骤；全新应用 store 默认打开正文 AI。

- 启用开关只由其自身交互改变；停用后连接测试和新运行零出站，启用后可重新设为默认。

  服务修订发出一次真实图片请求。成功时显示经过校验的一次性预览，关闭后清除且本地工作区、
  文章、素材目录和运行记录不变；失败留在弹窗中，结果不确定时不得提供同次确认内的再次请求。
- 未分配给正文、简介或图片步骤的服务可以确认删除，即使存在历史执行绑定；历史非秘密快照
  和血缘保留，目标凭据引用全部解除且不影响同一绑定中的其它 Provider。仍被当前步骤使用的
  服务返回稳定、可操作错误，删除失败会直接留在确认弹窗中显示。
- 使用用户在本机录入且具有可用额度的 OpenAI API Key 完成正文与简介，并使用 ARK API Key
  完成配图，至少一条种子真实走完正文、简介、配图和本地格式后进入待审核；证据不得包含
  密钥，并明确这是开发级真实 Provider E2E、不是发布候选。

  系统凭据就绪；用户逐次确认后，`execute` 必须生成一张能够完整解码、写入新私有文件并报告

  POST 结果未知、生成成功后的下载失败以及运行中退出均不得进入普通付费重试，下载 403/404

  包、陈旧连接器、停用、CLI 缺失或过旧、profile 未配置或未登录、权限不足、格式未完成和超限
  均在出站前失败关闭；任何失败不自动重试。
- 工作区 v9→v10→v11 迁移和二次打开幂等；遗留连接器秘密经独立待清理集合删除，CLI 凭据始终
  由 CLI 自己管理，不进入应用凭据生命周期。
- 在含空格、百分号和非 ASCII 字符的显式绝对应用数据目录中，`article list --json` 返回与
  Grid 默认顺序一致的单一 JSON 文档，查询前后数据库字节和目录文件集合完全相同；缺失数据库
  不会被创建。`article get --json` 精确区分 ID 大小写，且完整输出不包含任何本地图片路径。
- 父进程持续保持 stdin 打开时，文章查询仍在有界时间内完成；相对目录、缺失数据库、缺失文章、
  非当前 schema 和无效快照分别使用已定义的稳定错误与退出码，错误消息不包含绝对宿主路径。

## 明确非目标

- 不自动迁移、复制或删除被撤销身份命名空间中的用户数据、系统凭据和设备偏好，也不破坏性改写 Git 对象或提交历史；本次只清理当前维护树中的错误身份。
- 不把一个底层服务拆成三份重复凭据，也不迁移或复制现有系统凭据。
- 不复制飞书通用数据库、公式、自动化、视图设计器、评论或实时协作。
- 不回写或持续同步原多维表格，不读取飞书表格结构、公式、视图或历史数据；连接器首版只上传
  用户明确确认的最终 `.md`/`.html` 文件。
- 不把上传文件转换为原生飞书 Docx 块，不做双向/增量同步、覆盖更新、批量同步、定时发布、
  飞书以外连接器的真实 transport；这些能力需要单独范围确认。
- 不自动安装、升级或捆绑 `lark-cli`，不创建、删除、切换或修改共享 CLI profile，不接管扫码登录；
  不把 Markdown/HTML 之外的原生 Docx 作为本次发布格式。
- 不自动发布到内容平台，不规避验证码或平台风控。
- 不包含关键词研究、排名监控、自动事实核验、抄袭判定或 SEO 效果承诺。
- 不估算、补算或按字符、像素、价格推导 Provider 未返回的 token 用量。
- 不提供自由工作流、任意脚本、动态 Provider 市场、云端团队后台或跨设备同步。
- 不提供测试图片图库、测试历史或持久化测试素材。
- 文章 CLI 不提供新增、编辑、删除、运行、重试、审核、图片读取、历史正文展开、自动工作区发现、
  数据迁移、Provider/凭据管理或发布能力；这些写入与外部副作用继续只由已批准 GUI 交互触发。
- 配图基础编辑器不包含滤镜、文字、贴纸、画笔、抠图、AI 修图、上传替换、批量套版、导出或
  任意文件选择；不会改变图片 Provider、Prompt、生成协议或计费重试语义。
- 构建发布候选、签名、上传和渠道发布不属于本次变更。
