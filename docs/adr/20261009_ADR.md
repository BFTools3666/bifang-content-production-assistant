## 视觉与用语

- change_id：`UX-ARTICLE-PRODUCTION-OPERATOR-20261009`；required_version：`0.2.26`。
- 沿用毕方品牌、原侧栏和 Mantine 通用标准；设置业务入口以两列排列，窄屏一列，间距采用 `sm`，按钮内边距 16px、最小高度 76px。只改变四个入口的呈现；每个按钮自己拥有导航动作，名称和说明分别用于可访问名称与描述。
- 主要流程用“准备标题、制作正文、检查、导出”说明。把 Prompt/冻结/血缘/文章包等主要界面用语改为生成要求、开始时的设置、生成信息、文章版本。高级接口参数保留必要的准确术语。
- 已有文章制作中锁定其他动作时使用“请等当前任务完成后再操作”，避免把查看已完成内容误描述为重新生成。

## 工程边界

根 Cargo MSRV 与前端 engines/Rust 基线仍声明 Rust 1.95、Node 24.15+ 的兼容段、pnpm 11.24+，部分保留技能文字却写了更高门槛。本轮使用根技术事实允许、实际测试通过的 Rust 1.95 / Node 24.19 / pnpm 11.25；没有修改全局工具或声称验证更高门槛。该不一致需由独立 Harness 维护纠正，不能用本轮功能修复改写来源锁或制造已升级记录。
