# 2026-09-29 ADR

## ADR-20260929-001：接入隐私最小化 CloudBase 统计与共享版本发现服务

- 日期：2026-09-29；状态：Accepted；确认人：`arden`。
- 关联需求：用户要求检查当前统计模块是否接入环境 `bftoos-sh-d3ga7hahz59229f0a` 与版本更新服务；云端登记和统计资源已部署，但当前客户端没有接线，因此继续使用 `D:\workspace\bifang-operations-assistant` 的冻结协议完成客户端接入。`change_id = FEATURE-CLOUDBASE-PUBLIC-SERVICES`；版本门禁返回 `required_version = 0.2.17`，本发布周期功能位已存在，不额外提升版本。
- 决定：shared core 持有十字段 `daily_active`、严格七字段 application-version 响应、状态真值表和安全公网 HTTPS 规则；Tauri 适配器持有固定 CloudBase 路由、状态文件、日期认领、HTTP transport、低权限凭据、下载地址与退出生命周期；React 只展示 Rust 判定结果。
- 隐私边界：统计默认关闭并由设置页显式开启/撤回，只生成本应用随机 UUID v4，按北京时间每日最多尝试一次且请求失败不重试；不收集账号、硬件标识、AI 配置、凭据或创作内容。隐私说明固定为 `docs/privacy.md`。
- 版本边界：版本发现固定使用 `/tools/version-control/v1/versions/{code}/{currentVersion}`，构建宿主必须同时注入应用专属 Key/Secret，任一缺失即零 GET。服务提示按纯文本展示，下载 URL 只在 Rust 中保存和打开；强更由根级门阻断，`stopUpdate` 仅表示暂停分发。
- updater 边界：官方 Tauri updater 插件仍保持 `NotConfigured`、空 endpoint 与零出站，不承担本次版本发现，也不自动下载或安装候选。
- 云端事实：运营助手提交 `fad8cc79217bd3bbead6063721ba646a4b12faa2` 已登记本应用，部署独享 telemetry 函数、路由和集合，并通过合成 `daily_active` 在线验证；共享版本函数保持既有部署。本次不重复部署、不生成凭据、不购买资源、不写版本记录。
- 风险：当前构建没有运行时版本凭据，因此只能验证缺失凭据的零请求路径和注入 transport 的离线协议；真实客户端版本 E2E 仍未执行。系统浏览器能否成功处理下载链接仍依赖宿主默认 HTTPS handler。
- 验证：执行 core 与 GUI Rust 定向测试、前端公共服务定向测试、TypeScript 类型检查、Profile v2 校验/派生和遗留扫描；记录 CloudBase 已有收据。普通开发不声明发布候选、签名、公证、安装包或跨平台最终产物已经验收。
- 恢复或调整标准：如需默认启用统计、增加字段、跨应用关联、自动下载安装、广告、生成生产凭据或改变 CloudBase 环境，必须新增产品决定并重新评估隐私、凭据、付费与发布门禁。回退时删除客户端调用与设置入口，不删除云端历史数据或共享服务。
