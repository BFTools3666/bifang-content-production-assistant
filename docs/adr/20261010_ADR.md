# 2026-10-10 单篇首页与批量入口

- 状态：Approved（用户明确要求恢复此前的单篇首页，只改反馈项）。
- 关联需求：`docs/product_spec/20261010_product_spec.md`
- change_id：`UX-RESTORE-SINGLE-ARTICLE-HOME-20261010`；required_version：`0.2.29`。
- 背景：0.2.28 将批量工作台放到首页，运营人员进入「文章生产工作台」后看不到预期的单篇起点；标题弹窗同时暴露了过多设置。
- 决定：`/` 展示已有单篇流程，`/writer` 保持兼容；从单篇页按钮进入 `/batch`。侧栏名称改为「文章生产」。AI 标题生成固定 5 个候选并自动使用默认文本 AI，只展示平台、主题和候选选择。
- 影响与理由：恢复用户熟悉的操作顺序，保留已有批量、对标、风格、设置和数据用例；平台仍需用户选择，避免将百家号标题错误用于 CSDN。
- 风险与验证：回归测试覆盖标题生成、失败保留输入和单篇到批量导航；Windows 安装包仍须在 005 由用户试用。若以后改变首页，应以实际运营流程反馈重新确认。
