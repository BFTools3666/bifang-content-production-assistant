# 2026-10-08 决策

## ADR-20261008-001：两款创作者工具独立维护

- change_id：`MAINT-INDEPENDENT-CREATOR-REPOSITORIES-20261008`
- required_version：`0.2.25`
- 依据：用户明确要求把小红书从上次合并项目单独出来，成为两个项目。
- 决定：本产品「毕方内容生产助手」建立独立本地源码仓库，保留来源的全部可达历史、最新 Harness、业务 core 和商业许可；同款应用身份、数据和凭据命名空间不变。
- 规则例外：原 AGENTS 默认禁止派生项目；本次明确用户要求优先，仅授权这两款独立产品，不恢复通用派生入口。
- 风险：独立仓库可能漏同步通用修复。以共同来源提交和选择性同步追踪，不整仓覆盖。
- 替代验证：检查固定产品构建、前端显示和原有回归；未执行的新安装候选 Windows 验收保持待验证。
- 恢复条件：若用户之后决定重新统一仓库，保留两边新增历史后再普通整合，不能丢弃独立改动。

### 构建缓存复用

本机 shell 未提供 Cargo 命令。按此前该项目实际 Windows 构建脚本，复用已挂载外盘的既有工具链和缓存，仅为本次检查设置进程环境，不新安装工具或改写用户全局 PATH。该局部例外用于尊重用户低内存、内盘空间和既有外盘构建约定；未修改 Cargo 的 MSRV 或依赖版本。两款 Windows 目标检查均退出 0；检查包含测试代码编译，但没有执行 Windows 运行时测试，也未生成安装包。
