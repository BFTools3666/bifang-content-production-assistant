# 2026-09-22 ADR

## ADR-20260922-002：飞书发布改用官方 lark-cli 用户身份

- 日期：2026-09-22；状态：Accepted；确认人：`arden`。
- 关联需求：用户确认以本机官方飞书 CLI 代替应用内 App ID/App Secret 连接器鉴权。`change_id = FEATURE-LARK-CLI-PUBLISHING-TARGET`；版本门禁返回 `required_version = 0.2.11`。
- 背景：现有连接器直接调用飞书 OpenAPI，并要求每个应用工作区保存企业自建应用凭据；用户已经安装官方 `lark-cli`，希望复用其用户登录与权限，减少重复配置，同时继续保留多个发布目标、启停、默认项、显式确认、幂等和历史。
- 决定：应用只通过固定名 `lark-cli` 和参数数组调用 `>= 1.0.96, < 2.0.0`（2.x 尚未完成兼容验证），身份固定为 `user`，每个发布目标显式保存 profile 名称与文件夹 Token。Markdown 使用原生 Markdown 创建命令并通过 stdin 传递内容；HTML 在受控临时目录落一个相对路径文件后通过 Drive 上传命令发布。应用不读取 CLI token、不运行 shell、不接受任意命令或可执行路径、不切换共享 profile，也不自动安装或登录。
- 迁移：工作区 schema 提升到 v11。旧连接器保留稳定 ID、名称、目标文件夹、格式、历史和同步记录；旧当前修订写入历史，并建立新的停用修订且清除默认位，避免同一修订出现两种状态。旧 App Secret 引用进入原有可重试安全清理队列。CLI profile 和 token 不从旧凭据派生或复制。
- 可靠性与安全：所有调用都有超时、子进程终止、stdout/stderr 上限、JSON 信封校验和稳定错误映射；错误不得向 WebView 返回 token、原始响应或本机配置路径。配置保存零出站，测试只读列文件夹，发布仍要求格式阶段成功、版本冻结和用户二次确认，且不自动重试。
- 兼容性：连接器领域概念与既有 `FeishuDrive` JSON 类型暂时保留，以兼容工作区和同步历史；用户可见名称改为“飞书 CLI 发布目标”。当前只承诺 Markdown 原生文件与 HTML 原始文件，不新增原生 Docx。
- 风险：外部 CLI 缺失、版本变化、profile 未配置/未登录、权限不足或 PATH 差异会使发布失败关闭；Windows npm shim 的真实宿主行为未在本次日常实现中宣称已验证。失败时用户可在终端修复 CLI 状态后重新测试并手动确认发布。
- 恢复或调整标准：若官方 CLI 契约变化或用户要求应用完全自带登录，再单独评估 sidecar、OAuth、升级和凭据边界；不得静默回退到旧 App Secret 直连。回退本实现时仍需保留 v11 数据可读与遗留秘密清理，不能恢复已经清理的凭据。
