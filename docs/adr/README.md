# ADR 索引

本目录是毕方内容生产助手的产品边界变化、长期重要决定、持久策略变更和硬规则例外的唯一正文来源。

## 写入规则

- 文件名固定为 `YYYYMMDD_ADR.md`，日期使用决定确认所在时区的自然日。
- 只有长期重要决定、产品边界变化、持久策略变更和硬规则例外写入 ADR；普通需求、缺陷修复、纯重构、测试补强和内部清理不创建 ADR。
- 同一天只保留一个日期文件；新条目在当日文件顶部追加，并同步更新本索引。
- 每个条目至少记录状态、关联需求、稳定 `change_id`、`required_version`、背景、决定、影响、理由、风险、验证或替代验证，以及恢复或调整标准。
- 只记录本项目真实决定，不导入上游 Harness 的 ADR、批准历史或项目记忆。
