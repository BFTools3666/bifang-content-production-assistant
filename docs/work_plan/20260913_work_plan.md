  `bifang_content_production_assistant_cli/` 薄适配器及精确命中的 CLI 文档；不接入持久化、Provider 或 GUI。

  中性状态入口；这违反 `docs/CLI_CONTRACT.md` 的生命周期边界，不能在修复前把整体标为完成。

  无兼容别名，其 core API 与 GUI 启动元数据链路也已移除；版本门禁保持 `0.2.0`。
