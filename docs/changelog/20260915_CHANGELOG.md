# 2026-09-15 变更记录

## 变化

- `FEATURE-DETAIL-STAGE-GENERATION`（所需版本 `0.2.7`）：文章详情 Drawer 的正文、简介、配图和格式按钮现在与 Grid 共用同一精确单步命令，只生成或重新生成当前阶段，不再从当前阶段暗中继续后续 SOP。按钮下方持续说明单步边界，并按正文、简介、配图、格式顺序显示最早缺失的依赖、AI 配置或运行锁。
- 详情配图单步继续复用当前图片服务修订、模型、尺寸、水印和可能计费确认，取消零调用、一次确认最多一个请求；目标按钮独占 loading，稳定失败就近显示。已无调用的 `regenerate_article_stage` WebView/Tauri 外层命令已经移除，core 的安全版本化规则保持不变。
- `FEATURE-ARTICLE-IMAGE-EDITOR`（所需版本 `0.2.7`）：文章详情配图页签新增独立基础编辑器，支持 `25%–400%` 缩放、适应窗口、`100%`、平移、全屏、重置查看，自由与 `1:1`/`4:3`/`16:9` 裁剪、左右旋转、水平/垂直翻转、撤销/重做和恢复 AI 原图；查看零写入，关闭未保存草稿前会确认。
- 每次保存都从不可变 AI 原图按固定次序在 Rust 中重算，写入新的受管 UUID PNG 并建立派生文章包；AI 生成血缘继续保留，人工编辑另记来源 attempt、编辑 ID、时间和规范，包历史与批准历史不被覆盖。行/包/图片 attempt/编辑修订冲突会失败关闭并保留前端草稿，提交失败只清理本次新文件。
- 工作区 schema v8 为当前、包历史和批准历史中的图片分别初始化原图引用；WebView 会清空两类本地引用。受管读取新增 `25 MiB`、PNG/JPEG/WebP 魔数、完整解码、`4096×4096` 与 `128 MiB` 预算，Grid 缩略图缓存会随人工编辑修订刷新。
- `FEAT-RESIZABLE-DETAIL-DRAWER`（所需版本 `0.2.7`）：文章详情 Drawer 现在可从左边缘拖动扩宽，默认 `620 CSS px`、最小 `480 CSS px`、最大为当前窗口宽度，并在设备上记住用户确认的宽度；窗口临时缩窄不会覆盖原偏好，键盘也可完成微调和边界操作。
- Drawer 恢复为完整 WebView 上的 Portal 定位，修复嵌在主内容区后右侧控件被裁切的问题；六个页签、动作组、表单、图片和格式内容会随抽屉宽度换行或收缩，拖拽手柄在滚动长正文时仍固定可用。
- `BUG-ARK-REAL-E2E-PROBE`（所需版本 `0.2.6`）：火山方舟已生成图片后的 TOS 下载现在兼容 Clash/Mihomo TUN 返回的纯 `198.18.0.0/15` Fake-IP。该例外只作用于已通过官方北京 TOS HTTPS、443、无 URL 凭据/片段校验的地址；混合 DNS 答案、其它私网或保留地址仍被拒绝，TLS、禁重定向、无 Bearer 下载、大小和图片格式门禁保持不变。
- 同一桌面程序新增 `--ark-image-probe preflight|execute` 单次诊断模式。它只读现有工作区并复用系统钥匙串和正式方舟协议，预检零生成请求；真实执行还要求显式付费确认与独立输出目录，固定 Prompt、一次最多一个 POST、零自动重试，并只输出脱敏阶段及真实图片字节/尺寸证据。
- 修复热重载后，用户已在 macOS 应用中手动确认“生成测试图片”可显示真实方舟产物；本轮不再重复发起可能计费的验证请求。临时下载 403/404 的后端诊断原因改为地址失效或被拒绝，不再沿用 API Key 鉴权失败语义；图片测试界面仍统一提示结果不确定并要求先核对服务商记录。
- `FEATURE-PROVIDER-DELETE-PRESERVE-HISTORY`（所需版本 `0.2.4`）：未分配给正文、简介或图片步骤的 AI 连接现在可以直接删除，历史文章执行绑定不再形成不可见的删除门禁。
- 删除仍会保留历史中的非秘密 Provider 配置和文章血缘，但会解除目标 Provider 的全部历史密钥引用并进入安全清理；同一历史绑定里的其它 AI 服务保持不变。受影响旧阶段如需再次运行，应选择当前 AI 后重新生成。
- 删除失败时确认弹窗保持打开，并在操作位置直接显示可处理原因，不再只在页面顶部显示错误。
- `FEATURE-IMAGE-AI-CONNECTION-TEST`（所需版本 `0.2.4`）：图片 AI 当前服务新增“生成测试图片”。每次真实请求前明确提示可能计费并二次确认，取消保持零出站；测试绑定当前已保存配置修订，复用正式 OpenAI/火山方舟图片协议且只发送固定无文章数据 Prompt。
- 测试图经过原生下载、大小和 PNG/JPEG/WebP 格式校验后只在确认弹窗临时预览，关闭即从页面内存清除，不写入文章、素材目录或运行记录。失败不会自动重试，结果不确定时会提示可能已经计费并要求先核对服务商控制台。
- `FEATURE-GRID-STAGE-GENERATION`（所需版本 `0.2.4`）：工作台每行的正文、简介、配图和格式状态格新增“生成/重新生成”，每次只运行所点步骤，不再自动连跑后续步骤；依赖或当前步骤 AI 未就绪时直接在按钮位置说明。
- 单步运行带行版本、文章包版本和图片服务修订保护，只读取目标阶段的 AI 配置，格式步骤完全本地执行。配图在请求前显示当前服务与参数并确认可能计费，取消零调用、一次确认最多一次请求；运行记录会明确标记单步目标阶段。
- `BUG-GRID-CONTENT-PREVIEWS`（所需版本 `0.2.5`）：Grid 的正文与简介阶段现在直接显示三行缩略内容，点击即打开对应的可编辑详情页签；配图阶段直接显示固定缩略图，点击打开完整配图。预览、状态和重新生成互不代理，查看不会调用 AI。
- 配图缩略图只在可视区域附近由原生层按固定尺寸和资源上限生成，离开后释放；本地素材路径和远端临时 URL 不进入 WebView，过期产物可继续查看且仍明确显示过期状态。
