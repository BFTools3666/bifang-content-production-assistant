# 2026-09-14 变更记录

## 变化

- `FEATURE-STAGE-CENTRIC-AI-CONFIGURATION`（所需版本 `0.2.0`）：AI 配置页改为按工作流步骤展示独立的“正文 AI”“简介 AI”“图片 AI”入口，每次只编辑当前步骤的模型、参数和默认服务；保存时保留另外两个步骤的最新配置。
- 服务地址、API 密钥、启用/停用和删除集中到独立的“服务连接管理”区域。同一个 OpenAI-compatible 服务仍可被三个步骤复用，现有 Provider 数据与系统凭据引用无需迁移。
- 图片步骤不提供可能触发付费生成的独立连接测试；正文和简介仍可分别验证已保存配置。当前步骤在同一应用会话中保留，重新启动后回到正文步骤。
- `FEATURE-VOLCENGINE-ARK-IMAGE-PROVIDER`（所需版本 `0.2.0`）：图片 AI 新增“火山方舟 Ark v3”专用服务，预设方舟 API 根地址与用户提供的推理接入点 ID，支持 `2K`、水印和超时；正文、简介不会显示或绑定这个图片专用服务。
- 方舟请求固定采用单图、URL 返回、非流式协议，临时 URL 由原生层立即以不携带密钥的独立请求下载并保存为受管本地图片；POST 结果未知、生成成功后的下载失败或运行中退出均不会进入“仅重试失败”，避免再次付费生成。原 OpenAI Base64 图片协议和历史重试契约保持不变。
- `BUGFIX-LEGACY-ARK-PROVIDER-UPGRADE`（所需版本 `0.2.2`）：曾经按 OpenAI-compatible 保存、但明确指向方舟图片生成端点且只配置图片模型的旧服务会自动切换到正确的 Ark v3 协议；沿用原系统凭据引用，无需再次输入密钥，历史文章绑定保持原样。
- `BUGFIX-BATCH-PREFLIGHT-KEYCHAIN-HANG`（所需版本 `0.2.3`）：运行所选的确认预览改为只校验 Prompt、默认服务、能力与非秘密凭据引用，不再提前读取 macOS 钥匙串；只有用户确认正式运行后才读取密钥并进入真实 AI 调用。
