# 2026-09-30 变更记录

## 内容生产界面与 Windows 安装

- `BUG-CONTENT-PRODUCTION-TERMINOLOGY-20260930`（所需版本 `0.2.22`）：主业务入口和流程改为“内容生产、生产准备、生成内容、检查修改、保存导出”；小红书以“笔记”或“内容”称呼产出，主产品名称保持“毕方内容生产助手”。
- `BUG-WINDOWS-LEGACY-SEO-SHORTCUT-20260930`（所需版本 `0.2.23`）：Windows 主产品安装后，将符合发行者与目标程序核验的旧 SEO 同名快捷方式备份，避免桌面同时出现可误开的旧入口。原安装、工作区和凭据保留；小红书不受此安装钩子影响。
- 版本 `0.2.23` 的 Windows 安装、双机双版本真实使用与公司仓库合并仍以独立验收记录为准；构建和代码测试不代表上述验收已通过。

## 技术文章与图文笔记

- `BUG-PLATFORM-CONTENT-TYPES-20260930`（所需版本 `0.2.24`）：总入口仍为“内容生产”。主工具只显示 CSDN、百家号，明确生产技术文章；独立小红书版明确生产图文笔记。原批量文章工作台保留“文章”称呼，小红书版显示“笔记”。
- 小红书首步生成的是笔记文字，页面明确提示随后先生成简介、再制作配图；当前草稿导出只包含文字。图片服务继续使用原有单独配置。
- `0.2.23` 源码压缩包和中断的安装包构建仅为中间候选。最终 `0.2.24` 安装包必须在 RPA002、RPA005 两台 Windows 上分别安装两版并实际验收，验收前不合并主分支。
