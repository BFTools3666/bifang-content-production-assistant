# 2026-09-16 变更记录

## 变化

- `BUGFIX-IMAGE-EDITOR-SEPARATE-MODAL`（所需版本 `0.2.10`）：文章配图页在详情 Drawer 内只保留当前已保存图片预览和“高级编辑配图”入口；缩放、裁剪、旋转、翻转、撤销/重做和保存全部移入独立大弹窗。
- 图片编辑弹窗分别处理脏草稿确认、全屏查看与底层 Drawer 的关闭路径；保存未完成时禁止关闭，关闭后焦点返回实际触发控件。预览后台刷新失败会保留旧图并显示错误与零 AI 重试。

- `FEATURE-CLOUD-DOCUMENT-CONNECTORS`（所需版本 `0.2.8`）：新增独立“连接器”页面，首版支持飞书企业自建应用与指定云空间文件夹。可以保存、编辑、启停、删除和只读测试连接；App Secret 仅进入独立系统凭据库，页面永不回填，保存本身不联网。
- 文章格式页现在可选择已启用连接器，并分别确认把当前自包含 Markdown 或 HTML 上传为带文章包版本的 `.md`/`.html` 文件。同步携带行、包和连接器修订锁，相同成功键直接复用，失败不自动重试；首版不转换原生飞书文档、不做批量或双向同步。
- 工作区 schema 升至 v10，保存非秘密连接器配置、独立凭据引用/清理队列和同步记录；飞书 access token、App Secret、文章全文和外部响应不会进入同步历史。
- `BUGFIX-GRID-NO-HORIZONTAL-SCROLL`（所需版本 `0.2.9`）：工作台从十列收敛为“选择、文章信息、正文、简介、配图、格式”六列。状态、版本、双时间、错误和详情动作并入文章信息格，阶段按钮与缩略预览自适应收缩，移除 `1840px` 最小宽和 Grid 横向滚动条。

- `BUGFIX-FORMAT-TABS-RENDERED-PREVIEW`（所需版本 `0.2.8`）：文章详情的格式页不再上下堆叠 Markdown 与 HTML，改为等宽并列选项卡；每种格式都可切换源码和解释后的渲染效果，默认打开 Markdown 渲染效果，并在同一应用进程中保留选择。
- Markdown/HTML 复制内容现在会在内存中嵌入当前受管配图的完整 Data URL。源码显示折叠超长图片数据但复制保持完整；渲染预览使用严格结构白名单、空权限 sandbox 和禁止出站的 CSP。有图而读取失败时会阻止缺图复制并提供不调用 AI 的重新读取。
- `FEATURE-GRID-TABLE-STANDARDS-COMPLIANCE`（所需版本 `0.2.7`）：工作台 Grid 现在使用完整本地快照进行客户端分页，默认每页 `20` 条并可切换 `20`、`50`、`100`；标题搜索与总体状态筛选、排序、分页依次派生，“全选当前结果”继续覆盖全部筛选结果而不是只覆盖当前页。
- 工作台查询、筛选、排序、页码与每页数量在同一应用进程内跨路由保留，搜索、状态范围、排序或每页数量变化时回到第 `1` 页；成功载入后的越界空页只回退一次，加载、错误和第 `1` 页空结果不会形成回退循环。
- 首次加载、后台刷新、工作区无任务、筛选无匹配、首次读取错误和后台刷新错误现在分别呈现；后台刷新保留已有 Grid 内容并局部显示进度或错误，横向滚动限制在 Grid 自身容器内。
- `FEATURE-GENERATION-METRICS-CREATED-SORT`（所需版本 `0.2.7`）：工作台四个阶段格现在只在真实排队或生成状态显示转圈；生成中逐秒显示已用时间，结束后固定显示最近尝试的实际耗时。读取已有缩略图、打开详情和后台刷新不再显示生成动效。
- 每次 AI 请求只要 Provider 响应明确返回 usage，就会把输入、输出、总 token 逐字段保存到对应阶段尝试；随后产物校验、本地保存或方舟临时图片下载失败也不丢失。Grid 紧凑显示总 Token，详情历史显示三项明细；缺失 usage 或字段明确显示“Token 未提供/未提供”，不估算。本地格式转换固定显示 `0 Token · 本地处理`。
- 文章新增不可变创建时间与 Grid 创建时间列。新进程默认按创建时间倒序，相同时间按稳定文章 ID 倒序；更新时间、标题和状态排序继续可选。编辑、重新生成、图片保存和审核不会改变创建时间。
- 工作区 schema v9 会为旧文章从阶段开始、包历史、批准历史和已有人工配图编辑时间中选择最早证据；完全没有其它证据时才回退更新时间。旧阶段尝试的 token 用量保持缺失，不生成估算值。
