# 毕方内容生产助手

给内容运营人员使用的桌面工具：找对标、选择生产方式、生成内容、人工检查，再保存或导出。技术类长文章和小红书图文笔记分别提供独立的 Windows 安装版本。

> AI 生成需要使用者接入自己的 API 服务。本项目不附带 API Key 或免费生成额度。

## 先选适合你的版本

| 安装版本 | 适合的内容 | 平台 |
| --- | --- | --- |
| 毕方内容生产助手 | 技术类长文章 | CSDN、百家号 |
| 毕方小红书笔记助手 | 图文笔记；先完成文字，再制作配图 | 小红书 |

两个版本独立安装，草稿、对标、风格和 AI 设置分别保存在本机。主工具保留原有文章工作区；小红书版本使用独立数据目录。

## 第一次使用

1. **接入 AI。** 打开「内容生产」。页面会在未配置时提示「接入 AI」：DeepSeek 的接口地址和模型已有预填项，填入自己账号的 API Key 后保存即可。使用其他兼容服务时，可以在「更多设置」修改地址和模型。制作配图还需另行配置图片服务。
2. **选择这次怎么生产。** 第一次可以选「从主题生成」，输入主题和自己的资料；也可以选「参考对标作品生成」，或选已经保存的风格。
3. **生成并检查。** 技术类长文章核对标题、事实、代码和来源；小红书图文笔记先检查笔记文字，再进入图文工作台制作配图。
4. **保存或导出。** 草稿可继续编辑、复制或导出；需要继续制作内容时可进入工作台。飞书连接在后续制作流程中管理，同步前仍需确认。

API Key 保存在操作系统的凭据库，不写入源码、SQLite 草稿库或导出文件。没有可用 AI 服务时，工具会引导配置，不会直接发起生成请求。

## 找对标与保存风格

「找对标」支持输入关键词，或粘贴当前平台的公开作品、作者主页链接。在打开的采集窗口中查看页面，必要时由使用者自行登录，再采集已加载的作品。工具保存作品链接及页面公开可见的阅读或播放、点赞、收藏、评论等指标；平台未提供的数据会标为「未提供」，不会推算。

- **参考作品生产内容：** 选择已采集正文的作品，带入「内容生产」，结合自己的资料重新组织标题和内容；内置二创提示词可以查看、修改。
- **建立风格库：** 选择同一作者主页的 3 至 10 件已采集正文的作品，分析并保存写作特点。可保存多个风格，之后在「内容生产」中切换使用。
- **继续未完成的内容：** 已保存草稿保留生成来源、所用风格和提示词，重启后仍可编辑、复制或导出。

采集只读取页面已展示的公开内容；遇到登录或验证时，需要使用者自行完成。生成内容仍需人工核对，不应把对标作品直接当作可发布成稿。

## 代码与构建

本仓库包含共享业务逻辑、只读 CLI 和两个共用源码的桌面版本：

| 目录 | 用途 |
| --- | --- |
| bifang_content_production_assistant_core/ | 内容生产、工作流和稳定业务规则 |
| bifang_content_production_assistant_cli/ | 本地工作区的只读查询命令 |
| bifang_content_production_assistant_gui/ | React/Mantine 界面与 Tauri 桌面宿主 |

当前版本与目标平台以根目录的 [Cargo.toml](Cargo.toml) 为准。Windows 构建需要 Rust MSVC、Visual Studio C++ Build Tools、Node.js 和 pnpm；具体版本以 GUI 的 [package.json](bifang_content_production_assistant_gui/package.json) 为准。

在 GUI 目录安装依赖并启动开发应用：

```bash
cd bifang_content_production_assistant_gui
pnpm install --frozen-lockfile
pnpm tauri dev
```

从源码制作两个 Windows 安装包时，在仓库根目录依次运行：

```powershell
node tools/build-edition.mjs seo
node tools/build-edition.mjs xhs
```

命令中的 seo 是主工具的内部构建标识，软件展示名称仍是「毕方内容生产助手」。两个构建会使用各自的应用身份；每构建完一个版本，请先保存其安装包再构建下一个。构建入口和交付边界见[创作者工具说明](docs/CREATOR_TOOLS.md)，工程规则见 [AGENTS.md](AGENTS.md)。
