# 毕方内容生产助手

为 CSDN 技术文章、百家号长文章整理对标、生产内容并完成检查与导出。

这是独立产品仓库。名称、平台、应用数据目录和系统凭据身份已经固定；从本仓库启动或构建只生成「毕方内容生产助手」。

## 使用流程

1. **接入 AI**：打开「内容生产」，按提示填入自己的 API Key。DeepSeek 地址与模型已有预填项，也可以选择其他兼容服务。
2. **准备内容**：从主题和自己的资料开始，或先找对标作品，再选择参考作品、已保存风格等生产方式。
3. **生成并检查**：结合自己的材料生成标题和内容，检查事实、表达和来源；内置提示词可以修改。
4. **保存与导出**：保存草稿，继续修改或导出 TXT、Markdown、HTML；需要后续制作时进入工作台。

平台分别按 CSDN 技术文章和百家号长文章处理。“内容生产”是业务入口名称；SEO 和流量优化属于后续方向。

## 原有功能

- 找对标：按关键词或公开作品、作者主页链接采集已加载内容，保存链接及实际可见的互动指标。
- 风格库：从同一作者的作品分析表达特点，保存多个风格并在生产内容时选择。
- 内容生产：主题生成、参考作品生成、按风格生成；提示词可查看和修改。
- 草稿与工作台：编辑、保存、导出，以及原有简介、配图、排版流程。
- 服务连接：保留 AI 管理与飞书连接；飞书同步仍需使用者确认。
- 毕方公共服务：保留原统计、版本查询和更新提示；匿名统计默认关闭。

平台未提供的指标显示「未提供」。登录或验证由使用者在可见采集窗口中完成。API Key 使用系统凭据库，不随源码、草稿或导出文件分发。

## 开发与 Windows 构建

原 Rust core、React/Mantine、Tauri 宿主、Harness 和许可证均保留。内部 crate 目录沿用原名，避免无意义重命名和兼容变化。

```bash
cd bifang_content_production_assistant_gui
pnpm install --frozen-lockfile
pnpm tauri dev
```

在仓库根目录核对本项目身份：

```bash
node tools/build-edition.mjs --check
```

Windows x64 环境中构建本项目的 NSIS 安装包：

```powershell
node tools/build-edition.mjs
```

macOS 已配置 Windows 交叉编译环境时：

```bash
node tools/build-edition.mjs --windows-cross
```

无需选择发行版参数；指定其他产品会在编译前报错。产品身份由 [product-edition.json](product-edition.json) 同时供 Vite 和 Rust 构建读取。
