# 毕方内容生产助手

为运营人员准备标题、批量制作长文章，并完成检查、配图和导出。支持 CSDN、百家号，文章主题不限于技术领域。

这是独立产品仓库。名称、平台、应用数据目录和系统凭据身份已经固定；从本仓库启动或构建只生成「毕方内容生产助手」。

## 使用流程

1. **生产单篇文章**：首页「文章生产」先选平台和主题，可以参考对标作品或风格；按步骤生成、检查和导出。
2. **接入 AI**：首次使用按提示填写自己的 API Key。也可从「设置 → AI 服务」管理模型；文字和配图可分别选择服务。
3. **需要批量时**：从首页点击「批量生产」。可以输入主题让 AI 生成 5 个标题，选中后加入工作台，也可导入已有标题；再勾选文章批量制作正文、简介和配图。只需要正文时，点击文章行内「正文 → 生成」。
4. **检查并导出**：打开文章核对内容，保存修改后复制或导出。需要同步到飞书时，在「设置 → 飞书与云文档」连接并确认同步。

主题、受众和用途由使用者决定。找对标、使用风格库都是可选步骤；SEO 和流量优化属于后续方向。

## 原有功能

- 找对标：按关键词或公开作品、作者主页链接采集已加载内容，保存链接及实际可见的互动指标。
- 风格库：从同一作者的作品分析表达特点，保存多个风格并在生产内容时选择。
- 文章工作台：AI 标题候选、导入已有标题、批量制作；主题、对标或风格生成单篇文章。
- 草稿与工作台：编辑、保存、导出，以及原有简介、配图、排版流程。
- 服务连接：保留 AI 管理与飞书连接；飞书同步仍需使用者确认。
- 毕方公共服务：保留原统计、版本查询和更新提示；匿名统计默认关闭。

平台未提供的指标显示「未提供」。登录或验证由使用者在可见采集窗口中完成。API Key 使用系统凭据库，不随源码、草稿或导出文件分发。

## 开发与 Windows 构建

原 Rust core、React/Mantine、Tauri 宿主、Harness 和许可证均保留。内部 crate 目录沿用原名，避免无意义重命名和兼容变化。

```bash
cd bifang_content_production_assistant_gui
pnpm install --frozen-lockfile
pnpm tauri dev
```

在仓库根目录核对本项目身份：

```bash
node tools/build-edition.mjs --check
```

Windows x64 环境中构建本项目的 NSIS 安装包：

```powershell
node tools/build-edition.mjs
```

macOS 已配置 Windows 交叉编译环境时：

```bash
node tools/build-edition.mjs --windows-cross
```

无需选择发行版参数；指定其他产品会在编译前报错。产品身份由 [product-edition.json](product-edition.json) 同时供 Vite 和 Rust 构建读取。

发行版构建会先验证双语 `release-notes.json`、当前版本和资源映射，再携带更新日志打包。缺少日志或版本不符会停止，避免继续产出无法查看更新日志的安装包。管理员应使用上述构建入口，不省略发布专用配置。

检查更新通过公司的版本后台查询，后台须登记平台对应的应用 code 和下载地址；未登记、网络失败及无效响应会分别提示，不会显示成“已是最新版”。毕方统计逻辑保持原有实现，匿名统计默认关闭。
